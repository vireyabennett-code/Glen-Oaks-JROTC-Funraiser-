# JROTC LSU Fundraiser Tracker

A simple browser-based attendance tracker for JROTC LSU game fundraiser events.

## What it does
- Add LSU games/events
- Add cadets
- Mark each cadet Present/Absent for each game
- Automatically count games attended
- View an attendance report
- Export attendance as CSV
- Works on iPad/phone/desktop

## Important
This starter version stores data in the browser using localStorage. That means it is NOT a shared database: each device/browser has its own copy.

For a real staff-shared version, the next step is adding a secure backend/database and staff login. Do not put student contact information or other private student data into this demo before that step.

## Run it
Open `index.html` in a browser, or upload the three files to a static host such as GitHub Pages or Vercel.
